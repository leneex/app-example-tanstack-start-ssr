# TanStack Start SSR

Example [TanStack Start](https://tanstack.com/start) app with server-side rendering (SSR). TanStack Start is a full-stack React framework built on TanStack Router.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `3000` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# install dependencies
npm install

# run in dev mode with watch
npm run dev

# build for production
npm run build

# run the built app
npm run start
```
